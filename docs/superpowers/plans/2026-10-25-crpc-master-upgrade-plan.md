# CRPC 全方位升级总体规划

日期：2026-10-25
状态：待用户批准

## 目标

把 CRPC 打造成 modern C++（C++17 为主，兼容 C++20）最强、最易用的 RPC/服务器框架：

- 全方位提升 RPC 易用性（调用、服务定义、错误诊断、弹性默认、性能调优）
- 补全压缩算法（gzip/deflate/lz77/zip 等）
- 建设分布式测试与性能基准体系
- 提供微服务、网站 MVC、游戏网关-逻辑服务器三类完整示例，每个示例自带测试客户端
- 最后完善文档与上手资料

## 技术约束

- C++17 为主，兼容 C++20 编译；协程为 corocc 栈协程，C++20 `co_await` 仅在 C++20 构建条件启用。
- 构建：`scripts/build.ps1`；测试：`ctest`；基准：`crpc_bench_core`。
- 零警告（/W4 /WX）；ABI 门：`src/abi_check.cpp`。
- 所有改动须有红/绿测试与证据，记入 `.opencode/process.md`。

## 阶段与工作流

### Phase 0：核心易用性（按序）

1. **① 调用与返回体验**（设计已批准，spec: `docs/superpowers/specs/2026-10-25-crpc-rpc-usability-design.md`）
   - 统一 `response<Resp>`：同步/协程/回调/异步句柄/取消/组合。
2. **② 服务定义体验**
   - 声明式宏/属性、自动路由与参数绑定、零手写序列化。
3. **③ 错误与诊断**
   - 清晰错误码/异常、可观测性、日志、追踪。
4. **④ 弹性默认**
   - 超时/重试/熔断/限流零配置智能默认。
5. **⑤ 性能调优接口**
   - 简单开关调整压缩、批处理、并发、内存等。
6. **⑥ 压缩算法补全**
   - HTTP Content-Encoding：gzip/deflate（已有）+ 评估 brotli/lzma。
   - 帧级压缩：lz4（已有）+ 实现 zstd/gzip。
   - 独立 LZ77/DEFLATE 核心（可复用、可基准）。

### Phase 1：示例（每个自带测试客户端）

7. **⑦ 微服务示例**（`examples/microservices/`）
   - 治理：注册/发现、负载均衡、熔断、重试、限流。
   - 可观测性：追踪、日志、指标。
   - 运维：配置、健康检查、优雅退出。
   - 多协议：RPC + HTTP 跨服务调用。
   - 故障注入与弹性验证。
   - 全链路压测。
   - 测试客户端：`examples/microservices/client/`。
8. **⑧ 网站 MVC 示例**（`examples/web_mvc/`）
   - 路由/绑定/多格式序列化。
   - 文件上传/下载、Range/206。
   - SSE/长轮询。
   - 中间件/AOP。
   - 静态文件。
   - 配置/优雅退出。
   - 测试客户端：`examples/web_mvc/client/`。
9. **⑨ 游戏网关-逻辑服务器示例**（`examples/game_server/`）
   - 网关接入、协议解析、路由到逻辑服务器。
   - 状态同步、广播、房间管理。
   - 帧同步（lockstep）。
   - 高并发/压测。
   - 断线重连、心跳、优雅退出。
   - 安全/反作弊。
   - 测试客户端：`examples/game_server/client/`。

### Phase 2：测试与基准

10. **⑩ 分布式测试**
    - 多节点、分区、故障注入、确定性收敛。
11. **⑪ 性能与基准**
    - benchmark 体系、回归门禁、SLO。

### Phase 3：文档（最后）

12. **⑫ 文档与上手**
    - 教程、示例说明、迁移指南、API 参考。

## 顺序

① → ② → ③ → ④ → ⑤ → ⑥ → ⑦ → ⑧ → ⑨ → ⑩ → ⑪ → ⑫

## 成功标准

- 每个工作流有独立设计、实现计划、测试与证据。
- 每个示例可一键构建/运行，测试客户端断言通过。
- 分布式测试覆盖分区与故障注入。
- 性能基准可回归，关键指标有 SLO。
- 全量 ctest 通过，零警告，ABI 门通过。

## 风险

- 范围极大，需严格分阶段，每阶段独立可交付。
- 示例与测试客户端会放大维护面；优先保证核心工作流，再铺开示例。
- C++17/C++20 双构建增加 CI 成本。
