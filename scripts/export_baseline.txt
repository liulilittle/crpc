# Reviewed exceptions for scripts/export_gate.py.
#
# Format: <key>\t<reason>
#
# Keys:
#   class:<name>   a class in a public header with out-of-line members that is
#                  an implementation detail: it must NOT be exported, so it
#                  carries no CRPC_API. Adding a key asserts exactly that.
#
# Every entry is a decision, not a convenience. The gate fails on a stale entry
# as well as a missing one, so an entry cannot outlive the symbol it excuses.
#
# Regenerate with:
#   python scripts/export_gate.py --build-dir <dir> --update-baseline

class:crpc::net::detail::stream_factory	Internal bridge between net::connect/listener and tcp_stream. adopt() is called only from src/net/{connector,listener}.cpp, which are inside the DLL; every caller is library code, and the private tcp_stream constructor keeps consumers from inventing a handle. Exporting it would widen the ABI for a symbol no consumer can use.
class:crpc::net::detail::listener_factory	Internal bridge between the accept loop and listener. adopt() is called only from src/net/listener.cpp. Consumers reach a listener through net::listener::bind(); the native handle this takes is never public, so the factory cannot be invoked across the boundary.
class:crpc::net::detail::udp_factory	Internal bridge between the UDP receive path and udp_socket. adopt() is called only from src/net/udp.cpp. Consumers reach a socket through udp_socket::bind(); exposing the factory would expose the native handle type the header deliberately hides.
